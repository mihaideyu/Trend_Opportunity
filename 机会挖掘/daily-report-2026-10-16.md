## 一、今日热门趋势（5 条）

### 1. AI 从"降本工具"变成"成本黑洞"——企业级 Token 成本治理爆发
- **信号强度**：极高（多信源交叉验证，且有头部企业公开动作）
- **发生了什么**：SAP 于 2026 年 7 月 1 日发内部备忘录，暂停大部分差旅和非 AI 岗位招聘，仅保留客户对接差旅和核心 AI 岗位，官方理由是"Token 用量与相关成本随更多 AI 场景上线而激增"。CEO Christian Klein 亲自接管 AI 产品开发（代号 Project Fuji），并推出"AI Units"消费式计价替代传统按人头的 SaaS 订阅。Uber 在 2026 年 4 月就烧完了全年 AI 编码工具预算（仅用了 4 个月）；微软开始取消大部分内部 Claude Code 许可证，理由是 Token 账单失控。工程师 Peter Steinberger 披露其 OpenClaw 项目跑约 100 个 codex 实例，30 天内生成 6030 亿 Token、760 万次请求，API 花费超 130 万美元——关闭"Fast Mode"单一项即可省约 70%。
- **为什么重要**：这是 AI 商业叙事的拐点——过去两年行业一直在讲"推理成本沿曲线下降、可以激进上量"，现在第一次出现巨头为付自己 Token 账单而冻结招聘的公开数据点。Token 正在成为 CFO 眼中的"经营税"。
- **底层原因**：Agent 系统的无状态特性导致每步都重发全部上下文，编码类 Agent 任务消耗的 Token 是普通多轮对话的约 1200 倍、单轮推理的约 3500 倍；Agent 会陷入递归循环、过度查询、超出任务范围，且无法预判何时停手；成本由配置默认值而非模型本身驱动。
- **数据支撑**：SAP 股价一年跌约 47%；Gartner 预计 2026 全球 AI 支出 2.52 万亿美元（同比 +44%）；Goldman Sachs 预估 AI Agent 到 2030 年可能把企业 Token 需求放大 24 倍；某医疗机构 6 个月消耗 1 万亿 Token、产生 600 万美元计划外成本；85% 企业 AI 成本预测偏差超 10%，近 1/4 低估 50% 以上。
- **创业机会方向**：AI 成本管控与 Token 优化平台（模型路由、上下文剪枝、Prompt 缓存、用量上限/预算告警、成本归属到团队/场景、成本-价值双指标看板）；专为企业 CFO 的 Agent 支出可见性与治理层。
- **谁已经在做了**：Portal26（Agent Management Platform，主打发现+可见性+金融治理）、FastRouter.ai（按成本/延迟/质量路由到合适 LLM）、Navige（Product Hunt 今日上榜，切 AI Agent 成本与失控支出）、SAP 自己也开始卖 Token 治理白皮书和框架。
- **来源**：404 Media / Bloomberg / Yahoo Finance / Growth Acceleration Partners / portal26.ai / Product Hunt

### 2. AI 经济学遭遇现实检验——Character.ai 破产文件曝光
- **信号强度**：高
- **发生了什么**：Character.ai 的破产文件显示其商业模式经济学极差。HN 上引发大量讨论，核心结论是：AI 是"资本密集、不随规模线性摊薄成本、本质是商品、现金流长期为负、客户不愿按真实成本付费"——这与 VC 过去 20 年热爱的软件生意完全相反。
- **为什么重要**：这是继被 Google 2024 年"挖空"之后的终局确认，标志着二线 AI 玩家的跑道耗尽。模型层会像 90 年代浏览器战争一样被商品化、免费化，价值转向应用层与分发层。
- **底层原因**：模型是同质化商品，边际成本线性而非递减；消费者对按真实推理成本付费意愿极低；针对未成年人的 IP 角色陪伴产品还叠加了法律与合规成本。
- **数据支撑**：OpenAI 2026 年 10 月估值 8520 亿美元、年化收入约 500 亿美元；Anthropic 2026 年 7 月收入 run rate 650 亿美元、估值 9650 亿美元——头部还在涨，但二线已无生存空间。
- **创业机会方向**：不要做"又一个通用模型"或"又一个角色陪伴"，而应做模型之上有数据护城河、有明确付费方（B 端刚需）的垂直 Agent；或做帮 AI 应用把"免费用户"转化为"付费"的变现层。
- **谁已经在做了**：头部 OpenAI/Anthropic 垄断前沿模型；应用层有 Cursor、Wispr Flow 等已找到 PMF 的产品。
- **来源**：Hacker News（news.ycombinator.com/item?id=50089395）

### 3. "AI Coworker"（AI 同事）成为 Product Hunt 主导品类
- **信号强度**：高
- **发生了什么**：Product Hunt 今日/本月榜单被"AI 同事/Agent 基础设施"刷屏：Viktor.com（住在 Slack 里、能主动观察团队并建议自动化的 AI 同事）、Framer AI Agents（在画布上设计并发布网站）、Backdrop（为任意行业搭建 AI 同事）、Lleverage（实体经济的自主后台）、Busabase（AI Agent 的系统记录）、OpenMuse（可自托管个人助理）、Mastra Factory（从 issue 到生产由 Agent 跑完）。
- **为什么重要**：交互范式正在从"又一个工具/又一个标签页"转向"住在你团队已经使用的沟通渠道里的同事"。Viktor 的用户评价关键词是"proactive（主动）"——它不等你问，而是观察团队协作方式、主动插话并建议你没想过的自动化。
- **底层原因**：大模型从"回答问题"进化为"执行动作"，Agent 需要长期记忆、上下文与调度；用户对"多开一个工具"已疲劳，希望 AI 融入现有工作流（Slack/浏览器）。
- **数据支撑**：QuestMobile 显示中国办公交付型 Agent 商业化提速（腾讯 WorkBuddy、阿里 JVS Claw 近三个月活跃用户增幅分别 115.3%、164.4%）；Gartner 称仅 17% 企业已部署 Agent、超 60% 计划两年内部署。
- **创业机会方向**：为垂直行业/职能做"住在已有协作工具里的 AI 同事"（而非新 App）；Agent 的持久化记忆层、跨 Agent 协作协议（A2A）、Agent 的系统记录（system of record）基础设施。
- **谁已经在做了**：Viktor.com（Zeta Labs 团队，前身 Jace）、Framer、Backdrop、Directus 的 Monospace（Agent 的受治理 API 层）、tiun（AI 构建者的认证/计费/支付层）。
- **来源**：Product Hunt（今日上榜 + 月度 leaderboard）

### 4. AEO（Answer Engine Optimization，答案引擎优化）站上风口
- **信号强度**：高
- **发生了什么**：Exploding Topics 显示 "Answer Engine Optimization" 和 "AI SEO" 搜索量 5 年增长 99x+（"爆炸"级），"AI Recruitment Tools" +5800%，"AI Observability" +9300%，"AI Guardrails" +8400%。Product Hunt 本月有 ReSO AI（"当客户问 AI 时让你被发现和被推荐"）和 OpenSEO（开源版 Semrush 替代品）。
- **为什么重要**：流量分发逻辑正在改写——AI 搜索/答案引擎把"人找服务"变成"服务找人"与"被 AI 引用"。一份研究显示：LLM 引用的 URL 中仅 12% 出现在 Google 自然结果前 10，ChatGPT 与 Google 的重合度仅 8%。传统 SEO 的护城河正在失效。
- **底层原因**：ChatGPT 周活用户达 7 亿、日处理 25 亿+ prompt，用户行为从"搜索+点击"转向"提问+直接答案"；Forrester 称 89% 的 B2B 买家已把生成式 AI 作为自导式信息获取的核心来源；AI Overviews 导致点击率显著下降（Pew 研究）。
- **数据支撑**：ChatGPT 每条回答平均仅引用 2.62 个来源（Perplexity 6.61、Gemini 6.1）；ChatGPT 引用中 Wikipedia 占 7.8%、Top3 域名（Wikipedia/Reddit/TechRadar）控制 22% 引用；ChatGPT 推荐流量自 2024 年 7 月下降 52%，而 Reddit 引用上升 87%。
- **创业机会方向**：AEO 监测与优化工具（跨 ChatGPT/Perplexity/Gemini/AI Overviews 的品牌引用率追踪、内容可抽取性优化、E-E-A-T 权威建设）；"AI 引用率即新 KPI"的营销分析平台；帮品牌在 Reddit/Quora/YouTube 建立被引用资产。
- **谁已经在做了**：ReSO AI、OpenSEO、Profound、Peec AI、Jasper（GEO 产品线）、evergreen.media（AEO 指南）。
- **来源**：Exploding Topics / Product Hunt / evergreen.media / Jasper

### 5. GhostAction GitHub 供应链攻击卷土重来——CI/CD 安全成刚需
- **信号强度**：中高
- **发生了什么**：GitGuardian 与 Socket 披露，GhostAction 攻击 2026 年 8-9 月新一轮爆发，8 月 31 日至 9 月 30 日向 373 个 GitHub 用户/组织的 772 个公开仓库注入恶意 workflow，窃取 2577 个 secret（SSH 私钥 446、Azure 凭据 218、DockerHub/GHCR 142、数据库 112、AWS 106）。10 月 8 日又一轮 346 个仓库，受感染的维护者账号 kitao 和 henrywoo 把 `security-audit.yml` 推入包括 kitao/pyxel（18420 星）和 uber/athenadriver 在内的所有可写仓库。同一账号还在 6000 星的 DevOpsGPT 项目 Docker 镜像里植入 XMRig 门罗币挖矿程序。
- **为什么重要**：这是目前最大规模的 GitHub Actions 供应链攻击之一，且"从未真正停止"。攻击手法简单（伪装成安全 workflow 的 curl POST 窃密）却极难被普通开发者识别；被盗账号凭据被多个团伙复用。
- **底层原因**：开发者账号凭据泄露（infostealer/凭据库）后，攻击者用受害者身份提交"安全 workflow"绕过审查；GitHub 对 workflow 首次运行需人工审批的机制挡住了大部分，但真实流量提交仍会触发。
- **数据支撑**：累计约 1900 个账号被攻陷、3 万个仓库被盯上、3174 个 secret 被尝试窃取；3669 次 run 中 499 次执行、336 次成功、从 13 个仓库窃取 26 个 secret；仅 124 个仓库（16%）在 2026-10-05 前被清理。
- **创业机会方向**：CI/CD 供应链安全（GitHub Actions workflow 变更审计、secret 泄露实时监测与轮换、恶意 workflow 检测、依赖/镜像供应链扫描）；面向开源维护者的免费凭证轮换工具。
- **谁已经在做了**：GitGuardian、StepSecurity（Harden-Runner、secret exfiltration 策略）、Socket。
- **来源**：GitGuardian Blog / StepSecurity / The Hacker News

## 二、用户痛点（8 条）

### 1. AI 账单失控，财务团队"盲飞"
- **痛点一句话**：Agent 花钱没上限、没归属，财务只有在账单到了才知道。
- **典型用户画像**：企业 CFO/财务运营负责人，已推动 AI 但无法量化 ROI 的工程 VP。
- **具体场景**：Uber 把 Claude Code 开放给 5000 名工程师，4 个月烧完全年预算；微软因 Token 账单取消内部 Claude Code 许可证；财务试图用"按席位/年度合同"的旧工具去管"按 Token 连续消耗"的新成本。
- **为什么现有方案不行**：Token 消耗不出现在采购单、不映射到成本中心，跨部门并行 Agent 无仪表盘；PwC 称仅 12% 的 CEO 表示 AI 已同时带来成本与收入收益，36% 的 CFO 对"可衡量影响"没信心。
- **情绪强度**：强（财务-工程之间出现"踢皮球"，是压垮 Agent 项目的头号原因）。
- **付费意愿信号**：SAP 为省 Token 冻结招聘、微软砍许可证、医疗企业 600 万美元计划外账单——治理工具是刚需且预算充足。
- **来源**：portal26.ai / Growth Acceleration Partners / 404 Media

### 2. 传统搜索流量被 AI 蚕食，品牌"在答案里消失"
- **痛点一句话**：我在 Google 排前 10，但 ChatGPT/Perplexity 从不引用我。
- **典型用户画像**：依赖自然搜索获客的电商、SaaS、本地服务商的市场负责人。
- **具体场景**：QuestMobile 数据显示 2026 年 5 月传统搜索行业人均使用次数、时长同比分别下降 19.1% 和 13.5%；汽车之家内容被 AI 结构化调用的触达用户（1497 万）已相当于其 App 自有流量的 24.9%。
- **为什么现有方案不行**：LLM 引用与 Google 排名重合度仅 12%，ChatGPT 仅 8%；传统 SEO 工具测的是排名/点击，测不到"被 AI 引用率"。
- **情绪强度**：中强（有远见者焦虑，多数人还没意识到）。
- **付费意愿信号**：Jasper、Profound、ReSO AI 等 AEO/GEO 工具线密集上线，说明已有付费客户。
- **来源**：QuestMobile / evergreen.media / Product Hunt

### 3. 软件评论平台"真假难辨"，IT 决策者找不到深度信息
- **痛点一句话**：G2/Capterra 上全是 4.5 星的"好用"评论，我仍不知道哪个适合我的架构。
- **典型用户画像**：做高价值、多年期基础设施选型的 IT 负责人/CTO。
- **具体场景**：翻几百条激励性评论，看不到 API 限流、SSO 集成、数据驻留、灾备能力等决定成败的技术细节；填个表下载资料，几个小时内接到销售电话轰炸。
- **为什么现有方案不行**：G2 靠广告模式，付费厂商占满品类页；激励性评论（礼品卡/折扣）扭曲评分；2026 年 G2 已收购 Capterra/GetApp/Software Advice，四大平台集中后"伪客观"风险更高。
- **情绪强度**：中（既有用户普遍吐槽"评论有偏见/像推广"）。
- **付费意愿信号**：93% 软件买家购买前读评论，但付费方（厂商）与信任方（买家）利益冲突，存在"买方优先、免销售轰炸"的替代平台空间。
- **来源**：G2（Capterra 评论区）/ technologymatch.com / Facebook 2Checkout

### 4. 中小企业被"功能臃肿"的 SaaS 绑架
- **痛点一句话**：CRS/CRM/物业工具功能堆成山，我只要三个基本功能。
- **典型用户画像**：个体户/微型团队（房产中介、小房东、水电工、MSP、小律所、Etsy 卖家）。
- **具体场景**：房产中介被塞满用不上的功能、连"热线索管理+邮箱同步"都难用；管理 <10 套房的小房东还在用表格排清洁；承包商用报价 App 发错报价单泄露客户隐私。
- **为什么现有方案不行**：现有工具按大企业/大组合设计，价格与复杂度都错配；用户要的是"更少功能、做得对"。
- **情绪强度**：强且高频（Reddit 12,500 帖分析显示"要更简单而非更多功能"是跨行业共性）。
- **付费意愿信号**：$10-$99/月 的微 SaaS 定价即买即用，低流失（一旦上传租赁/台账就难迁移）。
- **来源**：Medium（50 SaaS Ideas from Reddit）/ Reddit r/SaaS 分析帖

### 5. 独立创作者/自由职业者的现金流与跟进失控
- **痛点一句话**：佣金链接断了没人提醒、赞助截止日期错过、客户欠款追不回来。
- **典型用户画像**：5000-50000 粉的微网红、自由设计师/营销人。
- **具体场景**：联盟链接失效、错过赞助交付日期、设计稿审批与付款催收靠人工。
- **为什么现有方案不行**：大 CRM 面向销售团队而非个人，价格与心智都不匹配。
- **情绪强度**：中。
- **付费意愿信号**：$9-$20/月 的轻量工具，一个被修复的链接就可能值几百美元。
- **来源**：Medium（50 SaaS Ideas from Reddit）

### 6. 法律/会计专业服务仍靠电话和纸质流程
- **痛点一句话**：客户接洽、取证、排期还靠电话、邮件和纸质表单。
- **典型用户画像**：独立执业律师、小型律所、税务师/会计事务所。
- **具体场景**：小律所客户接洽（intake）靠电话+纸表单；税务季客户预约混乱；起草文书要逐条人工核对引用与冲突。
- **为什么现有方案不行**：现有律所管理软件贵、按席位收费；AI 工具需"可引用、可核验"而非瞎编。
- **情绪强度**：中强。
- **付费意愿信号**：$39-$99/月 的"AI 律师助理"能替掉一部分人力成本，即买即回本。
- **来源**：Medium / Product Hunt（GLM-Legal，Z.ai 的法律合同审查模型）

### 7. 机场/会议/社区活动后勤混乱
- **痛点一句话**：RSVP 名单丢了、志愿者排班散落在 14 个表格里、停车场没预约。
- **典型用户画像**：小节日/婚礼/教会/社区活动组织者。
- **具体场景**：婚礼供应商沟通、志愿者换班、节日停车预约全手工。
- **为什么现有方案不行**：现有工具要么过重要么根本没覆盖这种"一次性、高强度"场景。
- **情绪强度**：中（痛点极具体、可感知）。
- **付费意愿信号**：$19-$199/场 的按次收费，婚庆季即卖即用。
- **来源**：Medium（50 SaaS Ideas from Reddit）

### 8. 卖家被平台封号恐惧支配（Etsy/Shopify）
- **痛点一句话**：一个合规误判就可能封店，且几乎没有申诉抓手。
- **典型用户画像**：Etsy/Shopify 中小卖家、Airbnb 房东。
- **具体场景**：商品被合规误判下架、账户被暂停、物流规则算错导致亏钱；房东仍用表格排清洁。
- **为什么现有方案不行**：平台申诉慢且黑盒；合规规则频繁更新，卖家无自动检查。
- **情绪强度**：强（关乎生计）。
- **付费意愿信号**：$12-$29/月 的合规检查+申诉模板工具，一次封店=利润归零。
- **来源**：Medium（50 SaaS Ideas from Reddit）

## 三、创意点子（6 条）

### 1. TokenGuardian —— 企业 AI 支出治理与模型路由平台
- **触发点**：SAP 冻结招聘付 Token、Uber 4 个月烧完预算、Peter Steinberger 130 万美元账单。
- **目标用户**：已部署 Agent 的中大型企业 CFO/工程 VP。
- **冷启动策略**：开源一个"Token 成本可视化 SDK"+ 免费审计报告，打进已受账单惊吓的企业（Uber 型案例是天然销售线索）。
- **差异化**：成本-价值双指标（不只降成本，还标出"值得的消耗"），区别于纯降本的竞品；模型路由+上下文剪枝+Prompt 缓存+用量上限四件套。
- **风险**：SAP、微软等大厂可能自研/云厂商原生免费提供；需在巨头反应过来前在中小企业建立心智。

### 2. CiteRank —— 跨 AI 答案引擎的品牌引用率监测
- **触发点**：AEO 99x+ 增长、LLM 引用与 Google 排名重合仅 12%。
- **目标用户**：SEO 团队/营销负责人，尤其是电商、SaaS、本地服务。
- **冷启动策略**：免费"你的品牌在 ChatGPT/Perplexity/Gemini 被引用吗"检测页，病毒式传播；抓取红队 Reddit/Quora 关键词。
- **差异化**：测"被 AI 引用率/份额"而非排名，给出可执行的内容可抽取性改造建议，跨平台对比。
- **风险**：Jasper/Profound 已有产品；AI 平台接口不稳，数据抓取易被反制。

### 3. VendorSignal —— 买方优先的 B2B 软件选型与销售屏蔽平台
- **触发点**：G2 收购 Capterra 等四平台后集中化、激励性评论泛滥、销售轰炸。
- **目标用户**：做高价值 IT 选型的 CTO/IT 负责人。
- **冷启动策略**：从网络安全/可观测性等高频选型品类切入，聚合"技术深度"信号（API 限流、SSO、数据驻留、灾备），承诺"联系信息不外泄"。
- **差异化**：买方优先、需求建模、免销售轰炸；技术深度而非"好用"评论。
- **风险**：与 G2 的流量/SEO 差距巨大，冷启动难；厂商变现模式与中立性冲突。

### 4. CI/CD 供应链安全体检（面向开源维护者）
- **触发点**：GhostAction 1900 账号、3 万仓库、恶意 workflow + 挖矿木马。
- **目标用户**：开源项目维护者、中小工程团队。
- **冷启动策略**：开源 CLI 扫描 `.github/workflows`，一键发现恶意/可疑 workflow 与 secret 引用；免费轮换指引。
- **差异化**：轻量、开源、面向个体维护者（GitGuardian 偏企业）。
- **风险**：安全市场巨头环伺；免费工具变现难。

### 5. 微 SaaS"更少功能"套件（小房东/承包商/微网红）
- **触发点**：Reddit 12,500 帖分析结论——用户要"更少功能、做得对"。
- **目标用户**：<10 套房小房东、个体承包商、微网红、独立律师。
- **冷启动策略**：在对应 subreddit/Facebook 群直接发帖验证，先收 10 个付费测试用户。
- **差异化**：只做 3 个核心功能（如小房东：租金提醒+维修排期+租约存档），$10-$20/月，低流失。
- **风险**：天花板低（单一品类年收入难破百万），需横向复制多品类。

### 6. Agent 的"系统记录与认证层"（Agent Registry + Billing）
- **触发点**：Product Hunt 的 Busabase、Monospace、tiun、withHuman 密集上榜。
- **目标用户**：构建/部署多 Agent 的 AI 创业团队。
- **冷启动策略**：做一个 Agent 身份注册 + 人类审批层（human approval）+ 计费支付的开源版，切入 YC 系团队。
- **差异化**：Agent 时代的"身份+计费+治理"基础设施，类比 Web2 的 Auth0+Stripe。
- **风险**：巨头云厂商与 tiun/CREEM 等已卡位，需找细分（如合规审批、审计留痕）。

## 四、潜在创业方向（3 个）

### 方向 1：AI 成本治理与 Token 优化（FinOps for AI / Agent）
- **市场规模**：Gartner 预计 2026 全球 AI 支出 2.52 万亿美元（+44%）；仅"企业 Token 治理"这一层，SAP 一家就涉及"三位数（亿美元级）金融风险"。
- **竞争格局**：Portal26、FastRouter.ai、Navige、SAP（自研 Token 治理框架）、云厂商（AWS/微软原生成本工具）与多家 FinOps 厂商；尚无垄断者，处于早期混战。
- **验证路径**：先做单点——给已"被账单吓到"的中小团队提供免费 Token 成本归因报告，验证他们愿意为"成本-价值双看板"付费；再扩展到模型路由与治理。
- **商业模式**：按被管理 AI 支出的百分比（如 2-5%）或按席位订阅，附开源内核获客。
- **风险与护城河**：云厂商免费原生工具是最大威胁；护城河在跨云/跨模型的中立性与成本-价值归因算法（把 Token 映射到业务产出），而非单点降本。

### 方向 2：AEO / AI 搜索可见性（品牌被 AI 引用）
- **市场规模**：ChatGPT 700M 周活、日 25 亿+ prompt，AI 搜索正替代传统搜索入口；传统 SEO 工具市场（Semrush/Ahrefs 合计年收入数十亿美元）面临被 AEO 工具切走。
- **竞争格局**：早期，玩家分散（Profound、Peec AI、ReSO AI、OpenSEO、Jasper GEO），尚无"AEO 领域的 Semrush"。
- **验证路径**：先做一个免费"AI 引用率检测"落地页，验证中小品牌的焦虑与需求；再做成监测+优化+权威建设的闭环订阅。
- **商业模式**：$99-$999/月 订阅，按监测的 AI 平台数量与关键词规模分层。
- **风险与护城河**：AI 平台接口与引用逻辑不稳定（产品迭代风险）；护城河在跨平台引用数据的积累与"内容可抽取性"优化方法论。

### 方向 3：Agent 基础设施——治理/审批/计费/记录层
- **市场规模**：Gartner 称 60% 企业两年内部署 Agent；Agent 计费、身份、审批、可观测性（AI Observability +9300%）是确定性需求。
- **竞争格局**：tiun（AI 构建者的认证/计费/支付）、CREEM 2.0、Busabase（Agent 系统记录）、Directus Monospace（受治理 API 层）、withHuman（人类审批层）；多点在各自细分，缺乏一体化。
- **验证路径**：从"人类审批层 + 审计留痕"切入（合规刚需、易验证），绑定 YC 系/开源 Agent 团队做设计伙伴。
- **商业模式**：按 Agent 数量/交易量计费 + 支付抽成。
- **风险与护城河**：云厂商与 Auth0/Stripe 可能下沉；护城河在 Agent 协议（A2A/MCP）兼容度与合规审计记录。

## 五、中文渠道观察（3 条）

1. **AI 原生 App 已系统性重构中国移动互联网底层逻辑**：QuestMobile 2026 半年报显示，截至 2026 年 8 月 AI 原生 App 用户规模达 5.37 亿，月人均使用次数 85.1 次（同比 +67.1%）；6 月豆包/千问/DeepSeek 活跃用户分别为 3.82 亿/1.67 亿/1.29 亿。28% 的行业面临"使用次数+时长"双降，传统搜索行业 5 月人均使用次数、时长同比分别下降 19.1% 和 13.5%。信号：AI 原生 App 以人均 92.7 次的使用频次形成结构性锁定，价值向 AI 平台归集——做"被 AI 引用"的内容/服务供给是明确机会。（来源：QuestMobile 2026 年 AI 应用市场半年报）

2. **国内 Agent 商业化提速，"生态办事型"率先跑通交易闭环**：QuestMobile 把国内 Agent 分为生态办事型（千问任务助理、微信小微、支付宝阿宝）与办公交付型；腾讯 WorkBuddy、阿里 JVS Claw 近三个月活跃用户增幅分别达 115.3% 和 164.4%。豆包于 2026 年 6 月 24 日推出付费版锁定六种办公场景。信号：办公交付型 Agent 正从"技术验证"走向"早期商业化"，MCP 服务数（魔搭社区）已超 5400 个，支付能力打通是"AI 原生商业"开启的标志。（来源：QuestMobile）

3. **中国"内容主权"回归——优质存量内容成为 AI 时代的增量入口**：QuestMobile 显示，汽车之家内容经 TOP3 AI 原生 App 结构化调用，间接触达 1497 万用户（相当于其 App 自有流量的 24.9%）；有驾、太平洋汽车的 AI 触达分别相当于自有流量的 3.8 倍和 113.8 倍；携程内容撬动 2850 万 AI 触达。信号：对国内内容/垂媒平台而言，"被 AI 引用量"正在成为独立于自有 App 之外的关键分发通路，AEO 逻辑在中国同样成立且数据更陡。（来源：QuestMobile）
